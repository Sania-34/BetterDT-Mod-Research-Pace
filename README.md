# Research Pace

Changes how fast new technologies appear in Devices Tycoon.

- **Slow** — ×2 slower
- **Normal** — as in the game
- **Fast** — ×2 faster

Only technologies below 125 research points per level are adjusted. 125 and above always use the game's own dates.

Works in memory only. Does not change game files or saves.

## Installation

1. Install [BetterDT](https://github.com/JelenXP/BetterDT/releases) if you don't have it.
2. Download this mod as ZIP.
3. Extract and move the `research-pace` folder into:
   `Devices Tycoon\mods\`
4. Done. Open **Settings → Mods** and choose **Slow / Normal / Fast**.

⚠️ **Warning:** The mod may work incorrectly.
